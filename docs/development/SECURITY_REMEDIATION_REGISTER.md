# OPHIREUM NETWORK (`OMPNETWORK`) — Security Remediation Register

| ID | Vulnerability / Gap Addressed | Remediation Implemented | File(s) | Verification |
|---|---|---|---|---|
| SEC-01 | Admin session tokens persisted in browser `sessionStorage` | Removed all `sessionStorage` token storage from `EnterpriseModal.tsx` and `AdminConsoleApp.tsx`; tokens are held strictly in JS memory with `HttpOnly`, `SameSite=Lax` cookie (`opm_admin_session`) and `credentials: 'include'`. | `src/components/EnterpriseModal.tsx`, `src/admin/AdminConsoleApp.tsx`, `src/server/auth.ts` | Code audit + `enterprise-remediation.test.ts` |
| SEC-02 | Missing server-side admin token revocation on logout | Added `jti` claims, bounded revocation registry (`revokeSessionToken`), and `POST /api/admin/auth/logout` that revokes the active token and clears the HttpOnly cookie. | `src/server/auth.ts`, `src/server/routes/adminRoutes.ts` | Post-logout `401` test in `enterprise-remediation.test.ts` |
| SEC-03 | Weak admin principal binding (`sub` / `role` drift) | `requireAdmin` verifies live DB `adminRecord.id === sessionPayload.sub && adminRecord.role === sessionPayload.role && adminRecord.isActive`. | `src/server/auth.ts` | Forged `sub` returns `403` in `enterprise-remediation.test.ts` |
| SEC-04 | Coarse 2-role admin authorization | Expanded RBAC to 9 least-privilege roles (`super_admin`, `admin`, `operations_manager`, `finance_officer`, `sales_officer`, `project_manager`, `developer`, `support_officer`, `auditor`) enforced via `requirePermission()`. | `src/server/auth.ts`, `src/server/routes/adminRoutes.ts`, `src/server/routes/aiRoutes.ts` | `auditor` mutation returns `403` in `enterprise-remediation.test.ts` |
| SEC-05 | Missing MFA for Admin & optional Client Portal accounts | Implemented zero-dependency RFC 6238 TOTP MFA (`generateTotpSecret`, `generateTotpCode`, `verifyTotpCode` with `crypto.timingSafeEqual`) for both Admin and Client Portal accounts. | `src/server/auth.ts`, `src/server/portal/portalRoutes.ts`, `src/server/routes/adminRoutes.ts` | TOTP unit & portal enrollment tests |
| SEC-06 | PostgREST `.or()` filter string interpolation risk | Replaced `.or(...)` interpolation in `findActiveAdminByEmail()` with separate UUID-validated `.eq('auth_user_id', ...)` and `.ilike('email', ...)` queries. | `src/server/db/supabaseRepository.ts` | Static review + build verification |
| SEC-07 | Non-constant-time appointment management token check & unvalidated reschedule dates | Switched appointment management token comparison to `crypto.timingSafeEqual`, added rate limiting, and enforced weekday/non-past validation on rescheduling. | `src/server/app.ts` | `enterprise-remediation.test.ts` |
| SEC-08 | Unbounded in-memory rate limiter map | Bounded `SlidingWindowRateLimiter` with `maxKeys = 5000` eviction and fixed client IP extraction using Express `req.ip` (`trust proxy = 1`). | `src/server/app.ts` | Code review |
| SEC-09 | Mutable `audit_logs` table | Added PostgreSQL `BEFORE UPDATE OR DELETE` trigger (`trg_audit_logs_immutable`) raising an exception on tampering attempts. | `supabase/migrations/003_enterprise_platform_expansion.sql` | Migration inspection test |
| SEC-10 | AI prompt injection & cross-tenant RAG leakage | Enforced strict `visibility` (`public`, `internal_admin`, `tenant_private`) + `tenantUserId` filtering in `CentralKnowledgeService` and wrapped retrieved snippets in `<untrusted_knowledge_context>` boundaries. | `src/server/ai/knowledgeService.ts` | Cross-tenant isolation test in `enterprise-remediation.test.ts` |
| SEC-11 | Unauthorized live payment activation | Enforced server-side `403` safety lock blocking `live_payments_enabled = true` via API without explicit owner sign-off and verified production credentials. | `src/server/routes/adminRoutes.ts`, `src/server/portal/payments/paymentAdapters.ts` | `403` safety lock test |
